# Square-root-free associator defects: submission package

**Status:** candidate. Manuscript draft for peer review; not yet submitted.

`main.tex` (amsart, about 15 pages) and `references.bib` are the sources. The
two tables are generated by `make_tables.py` from committed data; never edit
`tables/` by hand.

## Build

```sh
python paper/associator-defects/make_tables.py --check   # tables match data
cd paper/associator-defects && latexmk -pdf main.tex      # TeX Live 2023+
```

Build outputs (`main.pdf`, `*.aux`, …) are ignored by git. Regenerate them
from source rather than committing them.
