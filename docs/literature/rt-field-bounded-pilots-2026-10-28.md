## 1. Proposed experiments

Run independent, deterministic, precisely bounded witnesses in seven disciplines: (M) guarded triple-spread Gram comparisons on three fixed F5 configurations using the existing quadratic oracle; (T) P4 state-dependent rewrites and admissible face closure using existing pilot; (H) a fixed three-square cylinder over F5 demonstrating two homologous cycles and failure of single-witness hitting; (S) a forged finite route receipt with a recomputed hash versus independently pinned replay; (P) rational two-choice stochastic route probabilities with equal and unequal local path weights; (L) exact rational two-example SGD and momentum order dependence with full optimizer state; and (B) an explicit F5 reduction that collapses a nonzero integer swap defect. All observations are **finite**, not sampled from a population, and never labelled universality or benchmark speed.

## 3. Terminology

**Field-specific pilot:** one declared finite consumer object and reproducible observations, not a shared acceptance theorem. **Full-state effect:** all relevant vector/optimizer coordinates, not merely parameter weights. **Non-authoritative report:** recomputable JSON stdout, not committed `data/` evidence. **Bridge falsifier:** a representation that is non-injective or fails to preserve the target predicate. **Receipt digest:** checksum under independently supplied expected value, not an attestation of actor identity.

## 4. Hypotheses

F5 for the finite quadratic toy and cylinder; norm/spread denominators guarded, no unguarded square roots or ordering on F5; rational `fractions.Fraction` for stochastic and optimization scalars; deterministic full finite enumeration for the bounded P4 and topology fixtures; fixed exact values (no random seed needed). Canonical repository domain-neutral mathematics stays upstream in `finite-math-kernels`; pilots only import existing quadratic/route consumer oracles. The F5/rat comparison deliberately refuses unproved transfer. No training GPU, real LLM, authenticated producer or statistical population is involved.

## 5. Falsifiers and refusal conditions

A nonplanar zero triple-spread defect is **not** planarity; geometry-positive P4 swap may have unequal endpoints; null-valued residual norm is **not** zero vector; a cylinder class survives after deleting one boundary-cycle representative; a self-recomputed hash can be forged while failing independently pinned equality; equal endpoint does not force balanced route probabilities; equal parameters but unequal momentum implies unequal future training; mod-5 equality does not lift to integer equality. A pilot that hides any of these falsifiers fails.
