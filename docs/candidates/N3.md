# N3 — Shell collision statistics modulo ℓ

**Status:** candidate — Poisson law is a heuristic.

For a fixed Hurwitz-order convention, push the norm-(n) shell to a precisely
defined finite quotient. The sample-space denominator, projectivization, unit
action, and inclusion of zero-occupancy fibers must be explicit.

## Baseline experiment

The checked-in analyzer takes the complete occupancy vector and reports:

- sample size, number of bins, empirical and expected mean;
- variance and index of dispersion;
- Pearson statistic with adjacent expected-count bins pooled until adequate;
- total variation distance from the fitted finite Poisson law, with the tail
  folded into the last observed class;
- a deterministic SHA-256 digest of the canonical input.

This is descriptive evidence only. A fitted Poisson curve is not an
independence proof, and the same data cannot both choose orbit corrections and
validate them.

## Data generator (`experiments/n3/hurwitz_shell.py`, convention `hurwitz-mod-ell/v1`)

Exact enumeration of the norm-n shell Sₙ of the Hurwitz order on doubled
coordinates; reduction H → H/ℓH ≅ 𝔽_ℓ⁴ for odd primes ℓ ∤ n; the complete target
T = {v : Σvᵢ² ≡ n (mod ℓ)} with zero bins. Under `unit_action = left`, both Sₙ
and T are replaced by orbits of the 24 units. Fixed by tests:

- |Sₙ| = 24·σ₁(odd part of n) for n ≤ 200. The plain 24σ₁(n) holds only for
  odd n; this correction is now recorded as `HurwitzShellCountFinite`.
- |T| = ℓ³ − ℓ = |SL₂(𝔽_ℓ)|. The reduction is unit-equivariant.
- **The unit quotient leaves every fiber proportion unchanged.** The action
  is free and equivariant on both sides, so each plain fiber count equals
  its orbit's count and the plain histogram is exactly 24 × the orbit
  histogram. λ, dispersion and total variation coincide. Only the sample
  size changes, and with it the Pearson statistic. Significance claims must
  therefore use the orbit sample (`left`); the plain sample counts each
  orbit 24 times.

The committed baseline `data/n3/grid-v1.json` (`experiments/n3/grid.py`;
record `N3BaselineGrid`, an experimental result) covers ℓ ∈ {5, 7, 11, 13} at
λ ≈ 1–4. It is descriptive only. In it the dispersion index ranges over
roughly 0.29–1.37, so it neither supports nor refutes a Poisson law.
Note that for n < ℓ²/4 distinct elements cannot collide at all (x − y ∈ ℓH
forces N(x − y) ≥ ℓ²). The collision regime is therefore n ≫ ℓ², not merely
λ ≈ 1.

## Theorem route

Express factorial moments as congruence-constrained representation counts.
Identify the precise level-(ell^2) theta series and split Eisenstein and cusp
parts. Do not cite “exact formulas” until the relevant space, character, and
uniformity in the collision regime are established.
