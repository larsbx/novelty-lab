# N10 — Finite relation arithmetic

**Status:** candidate

An action effect is a binary relation on a declared finite state set
\(S\). Use union for alternative actions and define \(R;T\) by
\((s,u)\in R;T\) when some \(t\in S\) satisfies
\((s,t)\in R\) and \((t,u)\in T\). The empty relation is the union
identity, and the diagonal relation is the sequencing identity.

Use a synthetic publication workflow with draft, approved and published
states. Approval relates draft to approved. Publication relates approved
to published. The forward composition relates draft to published.
Reversed composition has no such witness. For a separate exhaustive
law check, use the 16 relations on a two-state carrier and all 4,096
ordered triples. Check associativity, both distributivity directions,
and identities. Replay composition witnesses as explicit intermediate
states, including two different witnesses for the same endpoint pair.

The literature gate should compare relation algebra, Boolean matrices,
and the repository's exact route audit. The proposed contribution is a
finite effect contract with auditable intermediate witnesses for the
N8 workflow. Its semantics describe possible state changes. Admission
is evaluated separately by N8.
