# N1 — Certified division and splitting decisions

**Status:** candidate — likely artifact contribution, not a claimed new theorem.

## Target

For a number field (K) and nonzero Cayley–Dickson parameters
(a_1,ldots,a_n), return `division` or `split` with a finitely checkable
certificate. The specification must fix the doubling convention and exclude
characteristic two.

## Certificate families to investigate

- (n=2): a quaternion local-invariant/Hilbert-symbol record sufficient to
  prove division or splitting. The “pair of ramified places” description is
  not yet accepted as a complete certificate specification: ramification,
  reciprocity, archimedean places, and the split case must be handled.
- (n=3): a place/sign certificate only after the exact Pfister-form
  local–global theorem and its hypotheses are pinned down.
- split: an explicit nonzero zero divisor, checked by exact multiplication.
  The promised size bound and the Cremona–Rusin reduction remain citations to
  verify, not implementation assumptions.
- (nge4): do not encode “always non-division” until a universal identity is
  proved for the chosen generalized doubling convention and base-field
  hypotheses.

## Work packages

1. Audit Lean/mathlib for number fields, places, Hilbert symbols, Pfister forms,
   quadratic forms, and Cayley–Dickson algebras.
2. Write a convention-complete mathematical specification.
3. Define versioned certificate schemas and a small independent checker.
4. Implement classical search separately from certificate verification.
5. Formalize the checker and the soundness link; benchmark certificate sizes.

## Promotion test

The contribution can become an **artifact contribution** once the checker is
sound, examples cover division and split outcomes, and the prior-art audit
shows that no equivalent verified pipeline already exists.
