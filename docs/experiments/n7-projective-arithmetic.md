# N7 independent finite projective arithmetic replay

The replay follows the [N7 candidate](../candidates/N7.md) at
`274e3e43b7488b017e4f539e3cbd2dc38c51055a`. The evidence applies to the
enumerated models below. The Python oracle lives in the experimental plane
with the candidate evidence. The programme and theorem registries retain
the candidate classification and open obligations.

| Domain | Coverage and independent reference |
|---|---|
| F₇² addition | 49 vectors and nine classes, including arithmetic zero. All 81 ordered class pairs and every one of the 49 fixed output vectors are checked against translated orbit intersections and the rank-defined support. Every representative regenerates its orbit. All 729 ordered class triples are composed in both orders and compared coefficient by coefficient with direct vector triple counts. Set associativity is checked on positive support. |
| F₇² multiplication | The polynomial u² − 3 has no root. All nonzero products are cross-checked against powers of 1 + u generated by a linear recurrence with period 48. Products of all representatives descend to the class table. Each of the 48 nonzero multipliers preserves every fixed coefficient. Multiplication by zero has a separate pushforward check for all 81 pairs. |
| Framed P¹(F₇) | All 336 ordered frames and 64 ordered point pairs in each frame. The chart-based reference includes affine sum and product, infinity cases and undefined outputs. All 36 rescalings of each operand pair are checked in every frame. All 216 rescalings of each triple of frame marks preserve the basis up to a common factor. |
| P²(F₃) | All 27 vectors, 13 points and 13 lines. Each line has four points. All 78 distinct unordered point joins and 78 distinct unordered line intersections are compared across cross products, incidence sets and, for joins, modular row rank. Every representative rescaling is checked. Diagonal point spans have rank one. |
| F₂² boundary | A repeated nonzero input has a single fixed outcome at arithmetic zero. This lies outside the q > 2 incidence contract. |

## Counterexamples and corrected identities

Let X = [1:0], Y = [0:1], and Z = [1:1]. Denote the fixed-output
coefficient by c and the raw output-orbit total by r. Every output
representative has the same count, so r(X,Y;Z) = |O_Z| c(X,Y;Z).
The factor is 6 at a nonzero F₇ output and 1 at arithmetic zero.

| Control | Exact result |
|---|---|
| Distinct X and Y, output Z | Fixed count 1, raw total 6. |
| Repeated X | Fixed coefficients 6 at zero and 5 at X. The corresponding raw totals are 6 and 30. |
| Substitute raw totals in the identity | r(0,X;X) = 6. The fixed coefficient is 1. |
| Substitute raw totals in associativity | At Y, ((X + X) + Y) gives 36 and (X + (X + Y)) gives 216. The fixed-output calculation gives 6 on each side. |
| Distribute zero over the integral multiset | Pushing forward X + X sends its full coefficient mass 11 to zero. Adding the multiplied inputs gives coefficient 1 at zero. Set support collapses to {0} on both sides. |
| Treat a homogeneous zero pair as a point | ∞ + ∞ and 0 × ∞ are undefined. In the same frame ∞ × ∞ and 0 + ∞ are ∞. Framed zero is [0:1]. |

## Lean boundary

[The Lean module](../../NoveltyLab/N7.lean) kernel-checks identity and
commutativity of fixed-output counts under the corresponding vector laws,
transport under an injective additive map, raw output scaling for a
constant coefficient, and coefficient associativity conditional on the
orbit expansion. It also kernel-checks the finite negative controls with
`decide`. The full bounded Lean replay is executable evidence. It exports
all three F₇ tables, the standard-frame outputs, and all F₃ lines, joins
and intersections. The normal gate compares the export with Python.

The remaining universal obligations are to construct the disjoint orbit
expansion with a representative of each class, instantiate the transport
lemma for arbitrary finite-field scalar and extension-field actions,
derive the general coefficients and incidence support, and prove framed
bihomogeneity, covariance and the rank characterizations over a field.
The bounded comparison supplies concrete instances and counterexamples to
overstrong formulations.

The repository pins Lean 4.24.0. Its immutable finite-math-kernels pin
`3bb94d317b8f0712591b33f9657cf3a0e54207cd` supplies Mojo arithmetic and
geometry, with no Lean library at that revision. The later upstream
`AcceptedField` module uses Mathlib and the upstream Lean 4.34.0-rc2
toolchain. This replay uses the existing `NoveltyLab.Oracle` vector
addition, subtraction and tensor multiplication and the existing Python
modular rank routine. Adoption of upstream Lean field semantics requires
a compatible immutable pin and a bridge from accepted scalar operations to
these orbit counts.

## Reproduction

From the repository root with Python 3.12 and the pinned Lean toolchain:

```sh
python -m experiments.n7 --check
python -m unittest discover -s tests -p test_n7_projective_arithmetic.py
scripts/verify_all.sh lean
```

The [fixture](../../tests/fixtures/n7_projective_arithmetic_v1.json) uses
zero-based class indices. Representatives are lexicographically ordered
with first nonzero coordinate 1. The arithmetic zero comes first in
the F₇ tables. The `fixed` and `raw` indices are left input, right input,
and output. Product cells hold class indices. Framed cells list sum and
product, using JSON null for an undefined result. Plane rows list two
point or line indices and the resulting line or point. The same ordered
coordinates label points and dual line normals.

`d251c078602f18c9284ee24aa507f6cb1df374f1a1c83c4931949bfdf36a021e`.
Generate it with `python -m experiments.n7 --emit`. Recompute it before using
its tables as a reference.
